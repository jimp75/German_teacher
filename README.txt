DEUTSCH LEHRER - installable offline app
=========================================

Host this folder once (free), then add it to your phone. HTTPS is required for
offline mode and for the microphone.

OPTION A - Netlify Drop (easiest, no account needed to try)
1. Open https://app.netlify.com/drop on a computer.
2. Drag the whole unzipped folder onto the page.
3. You get an https:// link. Open it on your phone.

OPTION B - GitHub Pages
1. Create a repository, upload ALL files from this folder to its root.
2. Settings > Pages > Deploy from branch > main / root.
3. Open the https://<you>.github.io/<repo>/ link on your phone.

INSTALL ON THE PHONE
- iPhone (Safari): Share > Add to Home Screen.
- Android (Chrome): menu > Install app / Add to Home screen.
Open it once online; after that it works offline.

NEW CONTENT
- In the app: Me > Content packs > Load file. Packs are in the packs/ folder.

UPDATING THE APP FILES
- Replace index.html, then change VERSION in sw.js (e.g. deutsch-v2) and re-upload.

Progress and packs are stored on the phone (per device). Use Me > Copy backup to move them.
